Silhouette Rhythm Game 수정용 프로젝트

이 폴더는 다른 컴퓨터에서 게임을 실행하고 수정할 수 있는 프로젝트입니다.
ZIP 파일 전체를 먼저 압축 해제한 다음 아래 순서대로 진행해 주세요.

1. Node.js 설치
   https://nodejs.org/ 에서 Node.js LTS를 설치합니다.
   Node.js 20.19 이상 또는 22.12 이상이 필요합니다.

2. Windows에서 실행
   START-EDITING.cmd를 더블 클릭합니다. 처음 실행할 때는 인터넷 연결이 필요하며
   필요한 프로그램을 자동 설치합니다. 브라우저가 열리면 게임을 확인할 수 있습니다.
   게임을 사용하는 동안 검은색 창을 열어 두고, 끝나면 그 창을 닫으면 됩니다.

3. 수정
   Visual Studio Code 같은 편집기에서 이 폴더 전체를 엽니다.
   - src/: 게임 동작과 화면 관련 코드
   - index.html: 게임 페이지 시작 파일
   - public/content/v2/silhouette/: 노래, 채보(.osu), 이미지 등 곡 자료
   - public/skins/: 게임 스킨 이미지와 효과음
   - public/catalog/v1/catalog.json: 곡과 난이도 목록 설정
   파일을 저장하면 실행 중인 개발 화면에 변경 사항이 반영됩니다.
   곡 파일 이름이나 경로를 바꾸면 catalog.json과 해당 곡의 manifest.json 등
   관련 설정도 함께 확인해야 합니다.

직접 명령어로 실행하는 방법 (Windows, macOS, Linux)
   이 폴더에서 터미널을 열고 다음 명령을 순서대로 실행합니다.
   npm install
   npm run dev -- --host 127.0.0.1
   표시되는 주소를 브라우저에서 엽니다. 처음 설치할 때 인터넷이 필요합니다.

배포용 파일 만들기
   npm run build
   완성된 파일은 dist 폴더에 만들어집니다. Vercel에 별도로 배포하려면
   이 프로젝트를 자신의 GitHub 저장소에 올리고 자신의 Vercel 계정에서 가져올 수 있습니다.
   기존 사이트를 수정하려면 해당 사이트의 저장소와 Vercel 프로젝트에 대한 권한이 필요합니다.

이 ZIP에는 기존 사용자의 배포 로그인 정보와 node_modules는 포함되어 있지 않습니다.

난이도별 랭킹
   메인 화면 왼쪽 상단의 트로피 아이콘 랭킹 버튼에서 난이도별 기록을 확인합니다.
   클리어 후 결과 화면에서 닉네임을 입력하고 기록 등록을 누르면 저장됩니다.
   로그인이나 회원가입은 필요하지 않으며 순위, 닉네임, 등급, 점수를 표시합니다.
   난이도별로 닉네임당 최고 기록 1개를 DB에 보관하고 상위 100명을 표시합니다.
   동점이면 정확도, 최대 콤보, 먼저 플레이한 시간 순서로 정렬합니다.
   실패 기록과 debug=1&profile=1 성능 측정 모드 기록은 랭킹에 등록하지 않습니다.
   온라인 랭킹은 Supabase PostgreSQL에 저장합니다. 같은 서버에 접속한
   다른 기기나 브라우저에서도 조회하며 브라우저 데이터를 지워도 남습니다.
   DB-SETUP.md의 안내에 따라 SQL과 서버 환경 변수를 먼저 설정해야 합니다.
   DB 미설정 또는 연결 실패 시에는 오류와 재시도 버튼을 표시합니다.
   기존 로컬 랭킹은 자동 업로드하지 않으며 DB 비밀 키는 서버에서만 사용합니다.
   로그인 없이 사용하는 닉네임이므로 닉네임 소유권과 점수의 진위를
   완전히 보장하지는 않습니다. 설정 안내의 보안 제한도 확인해 주세요.

성능 및 검증
   슬라이더 화면 좌표와 Path2D 경로를 캐시하고 화면 크기 변경 시 갱신합니다.
   일반 플레이에서는 디버그용 판정 상태 복사를 생략합니다.
   npm test: API, PostgreSQL 저장 함수, 랭킹 및 성능 최적화 회귀 테스트
   npm run build: 배포 번들 생성 및 35MiB 이하 배포 파일 검증
